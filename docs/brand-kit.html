01 / the mark

The Flow D

A bold geometric D drawn as a single pipeline. The bowl is a data conduit; two Pulse Mint nodes ride the curve — data packets in motion, becoming an API. The stem grounds it: infrastructure you can trust.

05 / voice

Direct. Concrete. Commercial.

The brand names the outcome, shows the proof, and never hides behind magic words. If a sentence could describe any tool, it describes none — rewrite it with a number.

01Name the outcome

“Production APIs in under 50 milliseconds” beats “blazingly fast.” Say what the user gets, not how it feels.

02Numbers over adjectives

Benchmarks, file counts, milliseconds. A claim with a number in it can be checked; one without can’t.

03No magic words

Never “revolutionary,” “seamless,” “cutting-edge,” “leverage,” or “unlock.” They promise everything and specify nothing.

04Short sentences

One idea each. Docs read like a good README — scannable, in order, done.

✓ on voice

“Point Datapi at a CSV. Get a tested FastAPI service, OpenAPI spec, and Terraform for Cloud Run.”

× off voice

“Datapi leverages cutting-edge AI to seamlessly unlock your data’s revolutionary potential.”

07 / usage rules

The don’ts

The mark only works one way. These are the fastest ways to break it — each one has shipped in a real deck somewhere.

×

Don’t rotate itThe pipeline runs left to right, level. Always.

×

Don’t stretch itScale proportionally or don’t scale at all.

×

Don’t recolor the nodesMint means data in motion. Other colors lie.

×

No gradients, no shadowsFlat on solid color — or use the app-icon tile.

  • No effects on the mark — no gradients, shadows, or outlines, ever.
  • No busy backgrounds — on photos or clashing color, use the app-icon tile instead of the bare mark.
  • Don’t rearrange the lockup — mark left, wordmark right, fixed spacing.
  • Don’t reset the wordmark — never in another typeface, never letterspaced, never capitalized.
  • Don’t rename it in writing — not “DataPi,” not “DATAPI,” not “Data API.” It’s datapi.
  • Don’t move the nodes — they sit on the curve where the source files put them.
